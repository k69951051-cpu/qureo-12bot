# بوت الكتب ومساعد التعلم — إصدار Gemini

هذا المشروع يحافظ على البوت العام وبوت الإدارة ومكتبة الكتب وربط Qureo، ويضيف مساعداً تعليمياً يعمل عبر Google Gemini.

## التشغيل على Railway

1. ارفع محتويات هذا المجلد إلى مستودع GitHub المرتبط بخدمة Railway، مع استبدال ملفات المشروع القديمة بالنسخة الجديدة.
2. اجعل أمر التشغيل `python main.py`.
3. اجعل Build Command: `pip install -r requirements.txt`.
4. في Railway → Variables أضف `GEMINI_API_KEY` وضع فيه مفتاح Gemini من Google AI Studio.
5. اترك `BOT_TOKEN` كما هو، ولا تضع مفتاح Gemini في `BOT_TOKEN`.
6. نفّذ Deploy ثم افتح البوت وأرسل `/start` واضغط زر `🤖 المساعد الذكي`.

> للتوافق المؤقت، يقرأ الكود أيضاً متغير `OPENAI_API_KEY` إذا لم يجد `GEMINI_API_KEY`. لكن يفضّل إنشاء المتغير بالاسم الصحيح `GEMINI_API_KEY` ثم حذف المتغير القديم بعد نجاح الاختبار.

## المتغيرات الأساسية

- `BOT_TOKEN`: توكن البوت العام من BotFather.
- `GEMINI_API_KEY`: مفتاح Gemini API من Google AI Studio.
- `ADMIN_BOT_TOKEN`: اختياري لتشغيل بوت الإدارة مع البوت العام.
- `ADMIN_IDS`: أرقام حسابات المشرفين، مفصولة بفواصل.
- `REQUIRED_CHANNEL`: قناة/جروب الاشتراك الإجباري أو `off` لتعطيله.
- `STORAGE_CHANNEL_ID`: اختياري لقناة تخزين ملفات الكتب.
- `QUREO_MODE`: `demo` أو `real` حسب إعدادات ربط Qureo.

## ملاحظات أمان

- لا ترفع أي ملف `.env` أو أي مفاتيح/توكنات إلى GitHub.
- إذا سبق نشر توكن Telegram أو مفتاح API في صورة أو محادثة عامة، ألغِه وأنشئ بديلاً.
- لا ترسل كلمة مرور Qureo إلى أي شخص؛ أدخلها فقط في مسار تسجيل الدخول المخصص داخل البوت.
- سجل محادثة Gemini قصير وموجود في ذاكرة تشغيل البوت فقط، ويُمسح عند إعادة تشغيل الخدمة أو باستخدام `/reset_ai`.

## ملفات المشروع

- `main.py`: نقطة تشغيل البوت العام وبوت الإدارة الاختياري.
- `bot.py`: البوت العام، الكورسات، المكتبة، Qureo، ومساعد Gemini.
- `admin_bot.py`: بوت إدارة وإضافة الكتب.
- `library.py`: قاعدة بيانات الكتب وتصنيفات المراحل والصفوف.
- `qureo.py`: ربط Qureo.
- `detect.py`: التعرف على بيانات الكتب من أسماء الملفات.
